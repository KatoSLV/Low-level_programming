# 💻 Low-Level programming in C
Welcome to my repository!

This repository contains my exercises learned in the C programming language.

It is focused on learning the fundamental concepts of C, memory management, and logical thinking.

## Scope

- Compilation process and basic C syntax
- Functions and nested loops
- Pointers, arrays, and strings
- Static and dynamic memory allocation
- Structures and typedef
- File I/O
- Variadic functions
- Basic data structures

Each directory contains exercises centered on specific concept

## Repo Structure

| Folder | Description |
|--------|------------|
| 0x00-Hello_world_and_Variables | Basic C programs: Hello World, variables |
| 0x01-Function_nested_loops | Functions and nested loops exercises |
| 0x02-More_functions_nested_loops | More advanced functions and nested loops |
| 0x03-Pointers_arrays_strings | Introduction to pointers, arrays, and strings |
| 0x04-More_pointers_arrays_strings | Additional exercises on pointers, arrays, and strings |
| 0x05-Even_more_pointers_arrays_strings | Further practice with pointers, arrays, and strings |
| 0x06-Argc_argv | Handling command line arguments (`argc` and `argv`) |
| 0x07-MallocFree | Dynamic memory allocation with `malloc` and freeing memory |
| 0x08-More_MallocFree | Advanced memory management exercises |
| 0x09-Structures_typedef | Using structures and `typedef` in C |
| 0x0A-Function_pointers | Introduction to function pointers |

Ongoing: exercises progressively added

Each directory includes:
- Source files (`.c`)
- Header files (`.h`) when required
- All programs are written in standard C and can be compiled using GCC:

```bash
gcc -Wall -Werror -Wextra -pedantic file.c -o output
./output
```
